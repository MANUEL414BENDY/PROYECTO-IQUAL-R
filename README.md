## 1. Descripción del Proyecto
Este sistema integrado surge para dar solución a la desorganización operativa en las áreas y recursos comunes de nuestro establecimiento escolar. El SGE unifica seis módulos críticos de gestión diaria en una sola plataforma web autogestionable por alumnos, profesores y personal de preceptoría.

## 2. Módulos Desarrollados
1. **Objetos Perdidos:** Catálogo público de pertenencias acumuladas en preceptoría con sistema de validación y solicitudes de devolución.
2. **Higiene e Infraestructura:** Canal interactivo de reportes de roturas y control de cronogramas de higiene del establecimiento edilicio.
3. **Buffet Paralelo:** Sistema de venta estudiantil de productos y gestión de donaciones para metas grupales de los alumnos.
4. **Planillas Digitales:** Registro y control de inventario digitalizado para los carros de computadoras y tableros de dibujo técnico del taller.
5. **Reserva de Sectores:** Calendario de solicitud y reserva del laboratorio de química, biblioteca y otros espacios comunes escolares.
6. **Inscripción a Educación Física:** Sistema de inscripción deportiva restringido por lógica contra superposiciones horarias con la teoría del curso.

## 3. Tecnologías de Desarrollo Proyectadas
* **Frontend:** Interfaces con maquetado basado en las Heurísticas de Usabilidad de Jakob Nielsen.
* **Base de Datos:** Base de datos estructurada SQL local para control de integridad y persistencia.
* **Control de Versiones:** Git y repositorio oficial en GitHub.
